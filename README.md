# Website address redirect

This repository will serve `https://xiaotianxu-astro.github.io/` and redirect visitors to `https://xtxuthomas.github.io/`.

The redirect preserves page paths, query parameters, and section links when JavaScript is enabled. The fallback link points to the main homepage.

Edit the main website in `xtxuthomas/xtxuthomas.github.io`. No synchronization or duplicate content is required here.

Publish the `main` branch from the repository root using GitHub Pages. Keep `404.html` identical to `index.html` so direct links such as `/reading/` also redirect.
